# NitroPatcherDS 使用说明

NitroPatcherDS 可以在 3DS／2DS、DSi／DSi LL（XL），以及使用 SuperCard miniSD 的 NDS／NDS Lite 上为 NDS 游戏卡带应用汉化等补丁。游戏运行时从卡带和存储卡读取内容，存档直接读写原卡带。

## 安装

### 3DS／2DS

需要一台已安装 Luma3DS 和 FBI 的 3DS／2DS，以及与补丁对应的 NDS 游戏卡带。

1. 解压 `NitroPatcher3DS.zip`，将其中的 `NitroPatcher3DS.cia` 和 `nitro-patcher` 文件夹复制到 SD 卡根目录。
2. 将补丁文件放入 SD 卡的 `nitro-patcher/patches/` 文件夹。文件夹中的 `Place patches here` 是空白提示文件。
3. 把 SD 卡装回主机，使用 FBI 安装 `NitroPatcher3DS.cia`。
4. 插入游戏卡带，从 HOME 菜单打开 NitroPatcherDS。

### DSi／DSi LL（XL）

需要一台已安装 Unlaunch 的 DSi，以及与补丁对应的 NDS 游戏卡带。Unlaunch 的安装方法见 [DSi Guide](https://dsi.cfw.guide/installing-unlaunch.html)。

1. 解压 `NitroPatcherDSi.zip`，将其中的 `nitro-patcher` 文件夹复制到主机 SD 卡根目录。
2. 将补丁文件放入 `nitro-patcher/patches/` 文件夹。
3. 把 SD 卡装回主机，插入游戏卡带，按住 A＋B 开机进入 Unlaunch 文件菜单。
4. 选择 NitroPatcherDS，确认下屏幕显示的路径为 `sdmc:/nitro-patcher/app/NitroPatcherDSi.nds`，按 A 启动。

需要设置快捷启动时，在 Unlaunch 的 `OPTIONS` 中将一个 `BUTTON A / B / X / Y` 选项指定为该程序，再选择 `SAVE & EXIT` 保存。以后按住对应按键开机即可打开程序。

也可以从 TWiLight Menu++ 选择 `nitro-patcher/app/NitroPatcherDSi.nds` 启动，将该程序的运行模式设为 DSi 模式、RAM disk 设为 None。如果加载器锁定了硬件访问权限，程序会自动通过 Unlaunch 重新启动，再进入卡带识别界面。补丁和程序都放在主机 SD 卡中，游戏卡带留在卡槽内。

### NDS／NDS Lite（SuperCard miniSD）

需要支持 DS 模式的 SuperCard miniSD、SuperFW，以及能够通过 FlashMe 进入 DS 模式的主机。

1. 解压 `NitroPatcherDS.zip`，将 `BOOT.NDS` 和 `nitro-patcher` 文件夹复制到 SuperCard 存储卡根目录。已有 `BOOT.NDS` 时先备份原文件。此包的 `BOOT.NDS` 是程序本体，字体和翻译包含在其中，请保留文件名称与位置。
2. 将补丁文件放入 `nitro-patcher/patches/` 文件夹。
3. 保持 Slot-1 为空，通过 FlashMe 以 DS 模式启动 SuperCard。SuperFW 会加载 `BOOT.NDS`。
4. 首次运行时选择语言，出现卡带提示后插入对应的正版 NDS 卡带，按 A 识别。没有检测到卡带时，可以插好后再次按 A。
5. 选择补丁，按 START 准备并启动游戏。运行期间保持 SuperCard 和游戏卡带插入。

如果进入程序时 Slot-1 已有卡带，按 A 后仍然无法识别，请取出并重新插入游戏卡带，再按 A。

补丁、配置和缓存都保存在 SuperCard 存储卡的 `nitro-patcher` 子目录中。程序内的 `sd:/` 路径也指向这张存储卡。

### 补丁目录

补丁需要直接放在 `patches` 文件夹内，程序只读取这一层的补丁文件。

## 支持的补丁

| 扩展名    | 内容                                        |
| --------- | ------------------------------------------- |
| `.xzp`    | NitroPatcher 格式的补丁包                   |
| `.zip`    | 内部结构与 XZP 相同的补丁包                 |
| `.xdelta` | 针对整份 ROM 制作的 xdelta／VCDIFF 差分补丁 |

XZP 补丁包可以直接使用，无需解压。ZIP 补丁包需要符合 XZP 的内部结构。下载包中另行附带的 `.xdelta` 文件，应取出后放入补丁目录。

选择补丁前，请确认补丁要求的游戏地区和版本与卡带一致。

### NDS／NDS Lite 上的 DSi 增强游戏

NDS／NDS Lite 可以运行《宝可梦 黑／白／黑2／白2》等 DSi 增强游戏的 DS 部分。准备 XZP／ZIP 补丁时，程序会提示游戏以 DS 模式运行，处理 DS 部分的文件和覆盖模块，并保留卡带存档读写。DSi 独占游戏和 DSiWare 不受支持。

NDS 无法读取完整的 DSi 区域，因此这类游戏默认开启“跳过 ROM MD5 校验”。仍需选择与卡带地区和版本相符的补丁。手动关闭此选项后，需要使用在 3DS／DSi 上完成 ROM MD5 校验的缓存。

这类游戏的整份 ROM `.xdelta` 补丁，以及包含整份 ROM 预处理的 XZP／ZIP 补丁，需要在 3DS 或 DSi 上准备：

1. 在 3DS／DSi 上使用同一张卡带，选择相同的补丁文件和启用顺序，完成准备。
2. 关闭主机，将 `nitro-patcher/cache/` 下对应卡带和补丁组合的目录复制到 NDS 存储卡的相同位置。需要校验 MD5 时，在 3DS／DSi 上关闭“跳过 ROM MD5 校验”后准备。
3. 在 NDS 上选择同样的补丁和顺序，按 START 复用缓存，以 DS 模式启动。

NDS 本地准备的 DS 部分缓存与完整缓存分开保存。需要在 3DS／DSi 上以 DSi 模式游玩时，请在对应主机上准备完整缓存。

## 选择补丁并启动

首次打开程序时，先选择界面语言。上下移动时可以预览对应语言，按 A 确认。

出现卡带提示后，插入游戏卡带并按 A 识别。读取成功后，上屏幕显示游戏图标和名称，下屏幕列出补丁。

1. 使用方向键上下移动，按 A 启用或取消补丁。
2. 按 START 启动游戏。
3. 首次使用该补丁时，程序会自动准备所需文件，完成后进入游戏。

程序会记住每个游戏启用的补丁及其顺序，下次打开时恢复选择。没有启用补丁和金手指时，按 START 启动原版游戏。

准备期间会显示处理步骤、进度、已用时间和预计剩余时间；处理文件时还会显示文件编号与总数。预计剩余时间按整个准备过程估算，会随实际处理速度调整。

添加补丁后，需要重新打开程序。更换卡带或误拔后重新插入时，按 X 打开菜单，选择“重新识别卡带”，按照提示插入卡带，再按 A。程序会恢复对应游戏的补丁选择。

### 同时使用多个补丁

补丁按照选中的先后顺序应用，列表左侧的 `[1]`、`[2]` 等数字表示顺序。需要调整时，取消选择后按所需顺序重新选择。

多个补丁应按照补丁发布者的说明组合使用。例如，某个修改补丁要求以汉化版为基础，就应先选择汉化补丁，再选择这个修改补丁。

可以混合选择多种补丁。每个补丁都以此前补丁的结果为输入；启用 ROM MD5 校验时，补丁要求的 MD5 也针对这个中间结果，预处理同样使用这个结果。顺序不符合要求时，可能在准备期间报错，请按照发布者的说明选择顺序。

## 金手指

将适用于 TWiLight Menu++ 的 `usrcheat.dat` 放入存储卡的 `nitro-patcher/cheats/` 目录。

1. 选择补丁后，打开 X → 金手指。需要准备补丁时，按 A 继续，按 B 返回。
2. 按 A 进入分类或启用、关闭代码，按 Y 阅读说明，按 SELECT 全部关闭。
3. 在分类内按 B 返回；在金手指主列表按 B 保存选择并返回菜单。
4. 返回补丁列表，按 START 启动游戏。

每个游戏及补丁组合分别保存选择。需要关闭补丁和金手指时，从菜单选择“启动原版”。

## 按键与触屏

| 操作             | 功能                                             |
| ---------------- | ------------------------------------------------ |
| 方向键上下       | 移动选择；阅读简介、错误详情或授权协议时滚动文字 |
| 方向键左右／L／R | 翻页                                             |
| A                | 在补丁列表选择或取消；在菜单中确认选项           |
| START            | 在补丁列表启动游戏                               |
| X／SELECT        | 在主界面打开菜单                                 |
| Y                | 查看当前补丁的信息和简介                         |
| B                | 按屏幕提示返回上一页                             |

下屏幕的列表项目和操作文字也可以直接点击。补丁文件名过长时，停留在该项目上即可查看滚动显示的完整名称。

补丁信息来自补丁包本身；没有附带名称、作者或简介的补丁会显示相应提示。

### 游戏中返回程序

通过 NitroPatcherDS 启动启用了补丁或金手指的游戏后，同时按住 L＋R＋↓＋B 约两秒，可以返回 NitroPatcherDS。返回前请先在游戏中保存进度。

NDS／NDS Lite 需要保持烧录卡插入。返回后，按提示拔出游戏卡带后重新插入，再按 A 识别。

3DS／DSi 同时关闭补丁和金手指、启动原版游戏时不支持此组合键。NDS／NDS Lite 启动原版游戏时同样可以使用。

## 菜单

- **金手指**：为当前游戏及补丁组合选择代码，数据库位置和操作方法见[金手指](#金手指)。
- **当前游戏的反烧录补丁**：开启或关闭 nds-bootstrap 内置的反烧录补丁，默认开启，按游戏保存。补丁作者要求关闭内置反烧录处理时，可在这里调整。
- **跳过 ROM MD5 校验**：开启后，准备 XZP／ZIP 补丁时跳过 `md5.txt` 的匹配要求，按游戏保存。默认关闭；NDS／DS Lite 读取 DSi 增强游戏时默认开启。此选项不会关闭 ZIP 和 xdelta 解码所需的完整性检查；整份 ROM 预处理需要根据 MD5 选择差分文件时，仍会计算 MD5。
- **启动原版**：关闭补丁和金手指，启动当前卡带。
- **重新识别卡带**：返回卡带提示页面，拔出卡带后重新插入，再按 A 识别。
- **环境报告**：生成用于排查问题的主机与 SD 卡环境报告。
- **界面语言**：支持多种语言，包括简体中文、繁体中文、日语、英语和韩语等；按 A 保存选择，按 B 恢复原来的语言。
- **修复内存卡**：检查整张存储卡的分配链、FAT 副本和空闲容量。当前使用的 FAT 检查通过且存在可修复差异时，按 A 备份文件系统元数据并同步 FAT 副本、更新空闲容量；备份保存在 `nitro-patcher/repair/`，页面会显示具体路径。存在交叉链接、遗失或无效分配链，或者无法确定正确 FAT 副本时，需要使用电脑备份并处理。修复写入期间保持电源开启，不要拔出存储卡。
- **关于**：查看软件版本、作者和使用的开源项目，按 A 可以阅读授权协议。

## 缓存和存档

首次准备完成后，缓存保存在 SD 卡的 `nitro-patcher/cache/`。以后使用相同版本的卡带、相同内容和顺序的补丁时，会直接复用缓存。补丁内容或组合改变后，程序会准备对应的缓存。缓存可长期复用。

需要释放空间时，可以在关闭主机后删除 `nitro-patcher/cache/`。下次启动会重新准备。游戏存档保存在卡带中，删除补丁缓存不会删除存档。

语言、补丁选择、金手指选择及每个游戏的反烧录补丁和 ROM MD5 校验设置保存在 `nitro-patcher/config/settings.json`。

对于包含 `md5.txt` 的补丁，关闭“跳过 ROM MD5 校验”后，之前跳过校验生成的缓存会重新准备并校验。NDS 上的 DSi 增强游戏需要改用在 3DS／DSi 上经过校验的完整缓存。

程序更新后，如果缓存的准备规则已改变，会在使用该补丁组合时自动重新准备。准备失败或中断留下的未完成缓存不会用于启动游戏，重新选择补丁并启动即可重试。

## 遇到问题

如果提示没有补丁，检查文件是否直接放在 `nitro-patcher/patches/`，以及扩展名是否为 `.xzp`、`.zip` 或 `.xdelta`。复制文件后重新打开程序。

如果提示补丁不匹配，按 A 查看详情，再按 B 返回检查补丁、卡带版本及多个补丁的顺序。

如果补丁的格式版本、文件名、目录或覆盖模块配置不受支持，也可以查看详情并按 B 返回，取消选择或更换补丁。下屏幕对应的操作文字支持触屏。

准备或启动失败时，记录错误详情。反馈问题时，请附上软件版本、游戏名称与版本、补丁名称和应用顺序，以及 SD 卡上的 `nitro-patcher/logs/prepare.log`。也可以从菜单生成环境报告，报告保存在 `nitro-patcher/logs/environment.log`。
