# NitroPatcherDS 使用说明

NitroPatcherDS 可以在 3DS／2DS、DSi，以及支持在 NDS 模式下使用 Slot 2 烧录卡的 DS／DS Lite 上为 NDS 游戏卡带应用补丁。游戏运行时从卡带和存储卡读取内容，存档直接读写原卡带。

## 安装

### 3DS／2DS

需要一台已安装 Luma3DS 和 FBI 的 3DS／2DS。

1. 解压 `NitroPatcher3DS.zip`，将其中的 `NitroPatcher3DS.cia` 和 `nitro-patcher` 文件夹复制到 SD 卡根目录。
2. 将补丁文件放入 SD 卡的 `nitro-patcher/patches/` 文件夹。
3. 把 SD 卡装回主机，使用 FBI 安装 `NitroPatcher3DS.cia`。
4. 插入游戏卡带，从 HOME 菜单打开软件。

### DSi

需要一台已安装 Unlaunch 的 DSi。

1. 解压 `NitroPatcherDSi.zip`，将其中的 `nitro-patcher` 文件夹复制到主机 SD 卡根目录。
2. 将补丁文件放入 `nitro-patcher/patches/` 文件夹。
3. 把 SD 卡装回主机。
4. 插入游戏卡带，按住 A＋B 开机进入 Unlaunch 文件菜单，选择 NitroPatcherDS，按 A 启动。
5. 需要设置快捷启动时，在 Unlaunch 的 `OPTIONS` 中将一个 `BUTTON A / B / X / Y` 选项指定为该程序，再选择 `SAVE & EXIT` 保存。以后按住对应按键开机即可打开程序。
6. 也可以从 TWiLight Menu++ 启动。

### NDS／NDS Lite

需要支持 NDS 模式的 Slot 2 烧录卡。目前已测试安装 SuperFW 的 SuperCard 烧录卡可以使用。

**注意**：NDS／NDS Lite 的运行严重受限，不推荐使用。建议优先在 DSi／3DS／2DS 主机使用。

1. 解压 `NitroPatcherDS.zip`，将 `BOOT.NDS` 和 `nitro-patcher` 文件夹复制到烧录卡存储卡根目录。
2. 将补丁文件放入 `nitro-patcher/patches/` 文件夹。
3. 通过 NDS 模式启动 SuperCard。如果已刷写 FlashMe，可以直接从主机菜单启动；也可以从支持引导 Slot 2 的 Slot 1 烧录卡启动。
4. 在 Slot 1 插入游戏卡带，SuperFW 会自动加载 `BOOT.NDS` 并启动。
5. 运行过程中，需要保持 Slot 2 烧录卡插入。

## 支持的补丁

| 扩展名    | 内容                                        |
| --------- | ------------------------------------------- |
| `.xzp`    | NitroPatcher 格式的补丁包                   |
| `.xdelta` | 针对整份 ROM 制作的 xdelta／VCDIFF 差分补丁 |

选择补丁前，请确认补丁要求的游戏地区和版本与卡带一致。

### DS／DS Lite 上的 DSi 增强游戏

DS／DS Lite 可以运行《宝可梦 黑／白／黑2／白2》等 DSi 增强游戏的 DS 部分。准备 XZP 补丁时，程序会提示游戏以 DS 模式运行。

NDS 无法读取完整的 DSi 区域，因此这类游戏默认开启“跳过 ROM MD5 校验”。手动关闭此选项后，需要使用在 3DS／DSi 上完成 ROM MD5 校验的缓存。

这类游戏的整份 ROM `.xdelta` 补丁以及包含整份 ROM 预处理的 XZP 补丁无法直接使用，需要在 3DS 或 DSi 上准备缓存：

1. 在 3DS／DSi 上使用同一张卡带，选择相同的补丁文件和启用顺序，完成准备。
2. 关闭主机，将 `nitro-patcher/cache/` 下对应卡带和补丁组合的目录复制到 Slot 2 烧录卡存储卡的相同位置。
3. 在 NDS 上选择同样的补丁和顺序，按 START 复用缓存，以 DS 模式启动。

## 选择补丁并启动

程序启动时会自动读取卡带；未插入卡带时，程序会提示，请插入游戏卡带并按 A 识别。读取成功后，上屏幕显示游戏图标和名称，下屏幕列出补丁。

使用方向键上下移动光标，按 A 启用或取消补丁，然后按 START 启动游戏。在补丁上按 Y 可以查看补丁信息。

首次使用补丁时，程序会自动准备所需文件，该阶段持续时间可能会比较长，完成后会自动进入游戏。程序会记住每个游戏启用的补丁及其顺序，下次打开时会复用缓存，启动时间将大大缩短。

如需更换卡带，按 X 打开菜单，选择“重新识别卡带”，按照提示插入卡带，再按 A。

### 同时使用多个补丁

补丁按照选中的先后顺序应用，列表左侧的 `[1]`、`[2]` 等数字表示顺序。需要调整时，取消选择后按所需顺序重新选择。

多个补丁应按照补丁发布者的说明组合使用。例如，《宝可梦》第四世代日文名字补丁要求以汉化版为基础，就应先选择汉化补丁，再选择这个补丁。顺序不符合要求时，可能在准备期间报错。

## 金手指

1. 将适用于 TWiLight Menu++ 的 `usrcheat.dat` 放入存储卡的 `nitro-patcher/cheats/` 目录。
2. 选择补丁后，打开 X → 金手指。打开金手指需要先准备补丁以计算校验码。
3. 按 A 进入分类或启用、关闭代码，按 Y 阅读说明，按 SELECT 全部关闭。
4. 返回补丁列表，按 START 启动游戏。

## 菜单

- **金手指**：为当前游戏及补丁组合选择金手指代码。
- **当前游戏的反烧录补丁**：可选择“默认／关闭／强制”，按游戏保存。“默认”按游戏和校验值自动匹配；“关闭”禁用内置反烧录补丁；“强制”忽略校验值，使用该游戏的反烧录补丁，有多份时自动选取第一份。部分汉化游戏已在汉化程序中包含反烧录补丁（例如《朋友收集》），需要在此关闭，否则会报错。
- **跳过 ROM MD5 校验**：开启后跳过 `md5.txt` 的匹配要求，默认关闭。NDS／DS Lite 读取 DSi 增强游戏时默认开启。注意，即使跳过了 MD5 校验，也可能因为需要应用 xdelta 文件而完整读取 ROM。
- **同时打开文件数上限**：可选择“无限制／16”，默认无限制，按游戏保存。准备补丁时出现文件打开失败，可以尝试设为 16，可能增加准备耗时。
- **同步读取等待**：3DS／DSi 上可选择“自动／开启／关闭”，默认自动，按游戏保存。游戏出现画面闪烁、局部错乱或上下屏内容异常时，可以尝试开启。
- **启动原版**：关闭补丁和金手指，直接启动当前卡带。
- **重新识别卡带**：修改游戏。
- **清理当前游戏缓存**：删除当前游戏相关的缓存文件。当需要清理空间，或已有的缓存文件出错时，可以尝试清理。
- **环境报告**：生成用于排查问题的主机与 SD 卡环境报告。
- **界面语言**：支持多种语言，包括简体中文、繁体中文、日语、英语和韩语等；按 A 保存选择，按 B 恢复原来的语言。
- **修复内存卡**：检查整张存储卡的分配链、FAT 副本和空闲容量。
- **关于**：查看软件版本、作者和使用的开源项目，按 A 可以阅读授权协议。

## 缓存

首次准备完成后，缓存保存在 SD 卡的 `nitro-patcher/cache/`。以后使用相同版本的卡带、相同内容和顺序的补丁时，会直接复用缓存。补丁内容或组合改变后，程序会准备对应的缓存。缓存可长期复用。

需要释放空间时，可以在关闭主机后删除 `nitro-patcher/cache/`。下次启动会重新准备。删除补丁缓存不会删除卡带中的存档。

## 遇到问题

如果提示没有补丁，检查文件是否直接放在 `nitro-patcher/patches/`，以及扩展名是否为 `.xzp` 或 `.xdelta`。复制文件后重新打开程序。

如果提示补丁不匹配，按 A 查看详情，再按 B 返回检查补丁、卡带版本及多个补丁的顺序。

如果启动后报错，已包含反烧录补丁的汉化游戏可以尝试关闭内置反烧录补丁；需要反烧录补丁但无法自动匹配的游戏可以尝试“强制”。

如果准备补丁时出现文件打开失败，可以在菜单中将“同时打开文件数上限”设为 16。3DS／DSi 上游戏画面闪烁或错乱时，可以尝试开启“同步读取等待”。

以上解决方案都已尝试，但仍然在准备或启动失败时，请拍摄记录错误详情。反馈问题时，请附上软件版本、游戏名称与版本、补丁名称和应用顺序，并将 SD 卡上的 `nitro-patcher` 文件夹打包提供。反馈链接：
